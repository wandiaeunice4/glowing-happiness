# Nothing is disallowed, and that is deliberate.
#
# Every page behind the Deriv connection carries noindex,nofollow in its own
# head. That is the stronger option, not the weaker one: a crawler told not to
# fetch a page never reads the noindex on it, so a URL somebody links to can
# still surface with no way to remove it. Letting the crawler fetch and read
# the tag is what actually keeps the page out.
#
# robots.txt is world-readable, so naming a page you would rather nobody found
# is an index of exactly what to go and look at. Listing home.html told anyone
# curious precisely where to start.
#
# /analysis/ holds the JavaScript and CSS the front page renders with. Blocking
# it stopped Google and Bing seeing the page as a visitor does, which cost more
# than it ever protected.
